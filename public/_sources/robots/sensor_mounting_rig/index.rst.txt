Sensor Mounting Rig
===================

Thor Developer Kit RealSense Rig
--------------------------------

The rig supports hardware mounting of three Intel RealSense cameras (D435/D455) on the Jetson Thor Developer Kit at known nominal positions.

The :doc:`thor_devkit_realsense_rig_description </robots/sensor_mounting_rig/thor_devkit_realsense_rig_description/index>` package provides the URDF files with the camera nominal positions, along with a launch file that publishes them.
