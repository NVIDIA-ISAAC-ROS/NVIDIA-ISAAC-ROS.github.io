Requirements
--------------------------------------------------------------------------------

Use the Isaac ROS source environment with CUDA-backed ``rosidl::Buffer`` support,
compatible middleware, and a CUDA GPU. Build the TensorRT engine and runtime
plugin for the same GPU and CUDA/TensorRT environment. Refer to the
:ref:`model setup requirements <graspgenx-model-setup>`.
