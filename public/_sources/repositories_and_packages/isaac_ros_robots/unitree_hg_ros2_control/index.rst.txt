===========================
``unitree_hg_ros2_control``
===========================

:ir_github:`<isaac_ros_robots> <unitree_hg/unitree_hg_ros2_control>`

Overview
--------

The ``unitree_hg_ros2_control`` package provides ROS 2 Control hardware
plugins for Unitree humanoid robots and Dex3 hands. The plugins exchange joint
commands and state with Unitree hardware through the Unitree SDK DDS channels.

The package includes the G1 and H2 system interfaces, Dex3 hand support,
diagnostic state tracking, CRC handling, and the plugin metadata required by
``controller_manager``.

Usage
-----

The :doc:`bring-your-own-embodiment guide
</repositories_and_packages/isaac_ros_deploy/how_to_guides/bring_your_own_embodiment>`
describes how the hardware interface fits into an Isaac ROS robot integration.

For the supported Unitree G1 launch flow, follow the :doc:`Isaac ROS Deploy
AGILE tutorial
</repositories_and_packages/isaac_ros_deploy/tutorials/deploy_agile>`.
