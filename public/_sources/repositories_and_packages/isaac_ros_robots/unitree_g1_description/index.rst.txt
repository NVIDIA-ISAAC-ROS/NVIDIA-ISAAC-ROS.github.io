==========================
``unitree_g1_description``
==========================

:ir_github:`<isaac_ros_robots> <unitree_g1/unitree_g1_description>`

Overview
--------

The ``unitree_g1_description`` package provides the Unitree G1 robot
description assets used by Isaac ROS. It contains xacro descriptions for the
real robot, MuJoCo, and Isaac Sim, together with their platform-specific
``ros2_control`` configurations.

The descriptions expose a consistent joint and sensor interface so the same
controllers can be used across simulation and real-hardware deployments.

Usage
-----

Refer to the :doc:`bring-your-own-embodiment guide
</repositories_and_packages/isaac_ros_deploy/how_to_guides/bring_your_own_embodiment>`
for an explanation of the description split and links to the G1 xacro files.

For a complete G1 deployment example, follow the :doc:`Isaac ROS Deploy AGILE
tutorial </repositories_and_packages/isaac_ros_deploy/tutorials/deploy_agile>`.
