=============================
Get Started with Manipulation
=============================

Set up your environment, then follow the setup guide for a simulated or physical
robot to build the packages and run a DisplayPort insertion workflow.
Isaac for Manipulation uses Isaac ROS core packages and its development
environment, including the ``isaac-ros`` CLI and ``ISAAC_ROS_WS`` workspace.

#. Review :doc:`requirements` for the documented robot configuration and the
   separate machines needed for model preparation or simulation.
#. Complete :doc:`Workspace and Developer Environment Setup <environment>`.
   This is required for both simulation and real-robot tutorials.
#. Choose :doc:`simulation` or :doc:`real_robot`. Each guide includes the package
   setup for its workflow. Prepare perception models only when that workflow
   requires them.

.. note::

   This documentation preview does not establish a release support matrix.
