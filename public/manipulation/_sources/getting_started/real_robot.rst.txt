=======================
Set Up a Physical Robot
=======================

First complete :doc:`Workspace and Developer Environment Setup <environment>`
on the robot deployment device and any model preparation host. This is the same
shared prerequisite used by the simulation tutorial.

Review the documented reference configuration in :doc:`requirements`, then
:doc:`install the packages and models <install>`. Choose the robot and gripper
specified by your workflow.

.. warning::

   Physical-robot setup and testing can command motion. Read the robot and
   gripper safety instructions, establish a safe workspace, and complete
   calibration and preflight checks before running a workflow.

Complete the following steps in order:

#. Follow :doc:`robot and driver setup </robots/index>` and the
   :doc:`detailed manipulation setup </reference_workflows/isaac_for_manipulation/tutorials/setup/setup_with_gripper>`.
#. Configure :doc:`cameras <sensors/index>` and complete manipulation camera
   calibration for your robot and camera arrangement.
#. Complete :doc:`manipulator testing </reference_workflows/isaac_for_manipulation/tutorials/setup/testing_manipulator>`,
   following the physical-robot instructions and their safety checks.
#. Run :doc:`DisplayPort cable insertion </reference_workflows/isaac_for_manipulation/tutorials/sim_to_real/tutorial_displayport>`,
   using its prerequisites and workflow configuration.

The detailed setup guide includes installation steps for readers who enter
directly. If those steps are already complete, continue with robot, camera,
and workflow configuration. For setup failures, refer to :doc:`/troubleshooting/index`.
