======================
``unitree_g1_bringup``
======================

:ir_github:`<isaac_ros_robots> <unitree_g1/unitree_g1_bringup>`

Overview
--------

The ``unitree_g1_bringup`` package provides the launch files, controller
configuration, and robot-specific policy configuration used to start a
Unitree G1 with ``ros2_control``. It supports the real robot and the simulated
hardware configurations used by Isaac ROS Deploy.

The package connects the robot description, Unitree hardware interface,
controller manager, reference-motion node, and optional inference graph into
one bringup flow.

Usage
-----

For build, launch, and policy deployment instructions, follow the
:doc:`Isaac ROS Deploy AGILE tutorial
</repositories_and_packages/isaac_ros_deploy/tutorials/deploy_agile>`.

The :doc:`bring-your-own-embodiment guide
</repositories_and_packages/isaac_ros_deploy/how_to_guides/bring_your_own_embodiment>`
uses this package as the reference layout for robot-specific bringup.
