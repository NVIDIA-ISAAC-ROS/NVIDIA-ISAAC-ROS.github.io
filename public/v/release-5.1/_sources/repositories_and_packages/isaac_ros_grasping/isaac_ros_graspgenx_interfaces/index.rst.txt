:ir_github:`<isaac_ros_grasping> <isaac_ros_graspgenx_interfaces>`

ROS 2 interfaces for the ``isaac_ros_graspgenx`` package.

.. list-table::
   :header-rows: 1

   * - Interface
     - Description
   * - ``msg/ObjectCloudReference``
     - Object ID and header of a segmented object cloud
   * - ``msg/SegmentedObjectCloudBatch``
     - Segmented object clouds from one acquisition
   * - ``msg/GraspCandidate``
     - Stamped grasp pose with a confidence score in [0.0, 1.0]
   * - ``msg/ObjectGraspResult``
     - Ranked grasp candidates and success flag for one object
   * - ``action/GenerateGrasps``
     - Generate grasps for one segmented object cloud
   * - ``action/GenerateGraspsBatch``
     - Generate grasps for each cloud in a segmented object cloud batch
