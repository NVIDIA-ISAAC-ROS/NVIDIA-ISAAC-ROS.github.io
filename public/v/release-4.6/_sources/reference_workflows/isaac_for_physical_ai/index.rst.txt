Isaac for Physical AI
=====================

`Isaac for Physical AI` is a reference architecture for collecting teleoperated humanoid robot 
demonstrations to fine-tune a
`GR00T N <https://developer.nvidia.com/isaac/gr00t>`__ policy and deploying this policy on a real or simulated robot.

The current release targets the `Unitree G1 <https://www.unitree.com/g1>`__ humanoid robot. We provide a step-by-step tutorial for a pick-and-place task 
(apple-to-plate), but the same workflow can also be used for other tasks.

The workflow is built from the following Isaac packages:

* :doc:`Isaac ROS Unitree G1 Teleop Bringup </repositories_and_packages/isaac_ros_physical_ai/isaac_ros_unitree_g1_teleop_bringup/index>` —
  XR / interactive-marker teleoperation.
* :doc:`Isaac ROS Unitree G1 Recorder </repositories_and_packages/isaac_ros_physical_ai/isaac_ros_unitree_g1_recorder/index>` —
  MCAP rosbag recorder with session management.
* :doc:`Isaac ROS Unitree G1 GR00T </repositories_and_packages/isaac_ros_physical_ai/isaac_ros_unitree_g1_gr00t/index>` —
  deploy launch for the fine-tuned GR00T policy.

Fine-tuning GR00T N and exporting the trained policy via LEAPP are performed
outside this repository using the
`nvidia-isaac/gr00t-leapp-export <https://github.com/nvidia-isaac/gr00t-leapp-export/tree/n17-export>`__
project (branch ``n17-export``); see the
external steps in the end-to-end tutorial below.
