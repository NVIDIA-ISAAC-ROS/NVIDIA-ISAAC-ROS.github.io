================================
Isaac Mission Control Tutorial
================================

Overview
--------

This tutorial simulates a virtual Nova Carter running Mission Client in Isaac Sim and assigns it
a mission using `Isaac Mission Control <https://github.com/nvidia-isaac/isaac_mission_control>`__.

Prerequisites
-------------

Clone the Mission Control repository and navigate into it:

.. code:: bash

   git clone https://github.com/nvidia-isaac/isaac_mission_control.git
   cd isaac_mission_control

All subsequent steps in this tutorial should be run from the root of this cloned repository
unless otherwise noted.

Tutorial Walkthrough
--------------------

#. Follow the :doc:`Isaac ROS Mission Client Tutorial </repositories_and_packages/isaac_ros_cloud_control/isaac_ros_mission_client/isaac_ros_mission_client>`
   through :ref:`starting the MQTT broker <isaac_mission_client_mqtt>`. Verify that you have the
   warehouse scene open in Isaac Sim along with Mission Client built and that the scene looks
   like the image below.

   .. figure:: :ir_lfs:`<resources/isaac_ros_docs/concepts/cloud_control/tutorial_warehouse_scene.png>`
      :width: 80%
      :align: center

#. From the root of the Mission Control repository, bring up Mission Control and its dependencies
   using Docker Compose:

   .. code:: bash

      cd docs/tutorial/docker-compose
      docker compose -f bringup_services_tutorial.yaml up

#. Follow the :ref:`launch Mission Client step <isaac_mission_client_launch>` of the
   :doc:`Isaac ROS Mission Client Tutorial </repositories_and_packages/isaac_ros_cloud_control/isaac_ros_mission_client/isaac_ros_mission_client>`
   to start the Mission Client. For reference, the command below is run inside the Isaac Docker
   container:

   .. code:: bash

      ros2 launch isaac_ros_vda5050_client_bringup isaac_ros_vda5050_client_nav2.launch.py init_pose_x:=-2.0 init_pose_yaw:=3.14159

#. Construct a navigation mission using the Waypoint Selection Tool:

   a. Run the following command from the root of the Mission Control repository:

      .. code:: bash

         docker compose -f waypoint_selection_ui/bringup_wp_selection_ui.yaml up --build

   b. Access the Waypoint Selection Tool web interface at ``http://localhost:8051``.

   c. Go to **Use Existing Files** and select ``carter_warehouse_navigation.png`` and
      ``carter_warehouse_navigation.yaml``. Click **Load Selected Files** to load the map.
      Verify that the map origin appears near the middle of the map as shown below:

      .. figure:: :ir_lfs:`<resources/isaac_ros_docs/concepts/cloud_control/tutorial_wpg_1.png>`
         :width: 80%
         :align: center

   d. Click on the map to define waypoints for the mission. Avoid placing waypoints on obstacles
      (dark areas on the map) or too close to an obstacle. For example:

      .. figure:: :ir_lfs:`<resources/isaac_ros_docs/concepts/cloud_control/tutorial_wpg_2.png>`
         :width: 80%
         :align: center

   e. Press **Generate Waypoints** to get the list of waypoints as x, y coordinates. Verify
      that the output looks similar to the following:

      .. code:: json

         [
           {
             "x": -2.9223684210526315,
             "y": 4.0245616712068255
           },
           {
             "x": 7.07763157894737,
             "y": 3.8666669343647193
           },
           {
             "x": 7.1828947368421066,
             "y": -5.922806749845808
           },
           {
             "x": -3.2907894736842085,
             "y": -5.922806749845808
           }
         ]

   f. (Optional) Click **Visualize Route** to preview the route generated by the Mission Control
      route planner.

      .. figure:: :ir_lfs:`<resources/isaac_ros_docs/concepts/cloud_control/route_example.png>`
         :width: 80%
         :align: center

#. Submit the mission through the Mission Control web interface:

   a. Open ``http://localhost:8050/api/v1/docs`` in a web browser.
   b. Expand the ``POST /mission/submit_mission`` endpoint and click **Try it out**.
   c. In the request body, create a JSON object with the key ``route`` set to the list of
      waypoints generated in the previous step. Press **Execute** to submit the mission.

      .. admonition:: Optional mission parameters

         Add the key ``iterations`` to specify how many times the mission should execute
         (default is 1). For example, to execute the route twice:

         .. code:: json

            {
              "route": [
                {
                  "x": -2.9223684210526315,
                  "y": 4.0245616712068255
                },
                {
                  "x": 7.07763157894737,
                  "y": 3.8666669343647193
                },
                {
                  "x": 7.1828947368421066,
                  "y": -5.922806749845808
                },
                {
                  "x": -3.2907894736842085,
                  "y": -5.922806749845808
                }
              ],
              "iterations": 2
            }

         If you want the robot to end at a specific pose, use the ``end_location`` parameter
         with ``exact`` set to ``true``. Set ``theta`` to the desired orientation in radians:

         .. code:: json

            {
              "route": [
                {
                  "x": -2.9223684210526315,
                  "y": 4.0245616712068255
                },
                {
                  "x": 7.07763157894737,
                  "y": 3.8666669343647193
                },
                {
                  "x": 7.1828947368421066,
                  "y": -5.922806749845808
                },
                {
                  "x": -3.2907894736842085,
                  "y": -5.922806749845808
                }
              ],
              "end_location": {
                "x": -2.5081181774400676,
                "y": -8.503454413823114,
                "theta": 1.57,
                "exact": true
              }
            }

#. After the response is received, verify that the Nova Carter navigates to the waypoints and
   completes the mission.

   .. figure:: :ir_lfs:`<resources/isaac_ros_docs/concepts/cloud_control/tutorial_mission.gif>`
      :width: 80%
      :align: center
