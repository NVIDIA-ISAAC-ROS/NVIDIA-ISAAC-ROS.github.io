Sim-to-Real Tutorials#

Overview#

These tutorials deploy DisplayPort insertion policies to physical robots. First complete Workspace and Developer Environment Setup, then the real-robot setup.

Available Tutorials#

DisplayPort Cable Insertion with FoundationPose, SAM, and cuMotion#

  • DisplayPort Cable Insertion with FoundationPose, SAM, and cuMotion

Use this tutorial when you want the complete Isaac for Manipulation workflow. It launches the workflow bringup and can use FoundationPose with Segment Anything for pose estimation. It then uses cuMotion to pick the cable and move to the socket hover pose, and runs the DisplayPort insertion policy through Isaac ROS Deploy.

DisplayPort Task-Space Policy Deployment#

  • DisplayPort Task-Space Policy Deployment

Use this tutorial when the cable is already grasped and you want to exercise only the learned insertion policy path. It starts the Flexiv driver and the DisplayPort task-space Deploy launch directly and asks you to publish the measured socket keypoint pose. It also includes a repeated insertion loop for multi-trial evaluation.

Improve Real-World Performance with SPARR (Experimental)#

  • Improve Real-World Performance with SPARR (Experimental)

Use this research workflow to learn a real-world residual policy on top of the simulation-trained insertion policy and raise success rates when the socket pose is noisy.
