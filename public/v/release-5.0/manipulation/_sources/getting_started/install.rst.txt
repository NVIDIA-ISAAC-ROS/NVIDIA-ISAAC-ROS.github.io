======================================
Install Packages and Perception Models
======================================

First complete :doc:`the environment setup <environment>`. These instructions reuse
the manipulation workflow's source-build instructions. Build the Isaac ROS
packages and their source dependencies in the same workspace.

Select the middleware for your target before building. Use
``RMW_IMPLEMENTATION=rmw_fastrtps_cpp`` for Isaac Sim, or follow the
:doc:`physical-robot middleware instructions
</reference_workflows/isaac_for_manipulation/tutorials/setup/setup_with_gripper>`
for real-robot deployment.
