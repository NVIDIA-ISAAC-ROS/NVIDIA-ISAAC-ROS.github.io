Isaac for Manipulation Setup Guide
==================================

Overview
--------

Prepare the hardware and software used by the DisplayPort pickup and insertion
tutorials. First complete :doc:`Workspace and Developer Environment Setup
</getting_started/environment>`, the shared prerequisite for both simulation
and real robots. Then choose the robot setup below and run the relevant
component checks before continuing to :doc:`the tutorials <tutorials>`.
