Methodology
-----------

The performance numbers provided above are measured using 
:doc:`Isaac ROS Benchmark </repositories_and_packages/isaac_ros_benchmark/index>`. 
Configuration files for reproducing results are provided in the launch scripts for each benchmark 
:ir_repo:`here <isaac_ros_benchmark> <benchmarks>`.

Frames per second (fps) report observed throughput from the input node through the
computational pipeline to the output node. The input rate is auto-tuned with a
target of less than 5% frame loss; these approximate results include some runs
slightly above that target. Average fps is computed over five runs, discarding
the minimum and maximum. Latency is the time from the first sent frame to the
first received frame in a separate 30 Hz trial from the same benchmark run.
Latency is omitted when no valid 30 Hz measurement is available.
