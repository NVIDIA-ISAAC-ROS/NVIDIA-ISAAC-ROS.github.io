# Isaac ROS Robots

ROS 2 packages for supported humanoid robots, including robot descriptions, ROS 2 control plugins, and hardware bridge packages.

## Overview

Isaac ROS Robots contains ROS 2 packages for
supported humanoid robots, such as the Unitree G1, including robot descriptions, ROS 2
control plugins, and hardware bridge packages for deploying to real robots.
