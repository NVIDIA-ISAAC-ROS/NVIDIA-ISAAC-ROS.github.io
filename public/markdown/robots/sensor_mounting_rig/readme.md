# Sensor Mounting Rig

This repository contains the URDF descriptions, meshes, and launch files for mounting sensors onto NVIDIA Jetson Developer Kits.

Visit [Sensor Mounting Rig](https://nvidia-isaac-ros.github.io/robots/sensor_mounting_rig/index.html) to learn how to use this repository.
